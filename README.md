## 概要 / Overview

本リポジトリは、`TownOfHost_Y`（TOH_Y）をフォークし、Modが使用できるように修正を行っていたものです。  
修正内容を本家リポジトリへ直接プルリクエスト（PR）として送信・反映することになったため、本フォーク版の役割は終了いたしました。

This repository was created to fork `TOH_Y` and fix it so that mods could be used.  
Since the fixes have been directly submitted to the official repository via a pull request, this fork is no longer needed.
